# Known limitations after the third milestone

- Learning effectiveness, reading level and age appropriateness need a parent/teacher and child usability pilot. The mastery score is an explainable practice heuristic, not a diagnostic assessment.
- German interface with English or French target content; one active course and learner per browser. Switching courses requires deliberate backup if prior progress should be retained. Only English has a supplied textbook-derived fixture; the French fixture is a synthetic technical test. A generated French course still needs content review against the user's school materials.
- Core production flows are verified in Chromium on macOS, including emulated phone/tablet viewports. Safari, Firefox, installed-PWA behavior and real devices are not yet separately certified.
- First loading requires access to a static server over HTTPS or localhost. Offline use starts once the shell is cached. Browser storage deletion/quota/private-mode restrictions remain platform constraints; user-downloaded backups are the recovery path.
- Backups preserve all recorded progress and completion rewards, but not an in-progress cursor or unsubmitted drafts on another device. Local reload resumes answered progress; unsubmitted text may need re-entry. No raw child-written text is retained in the backup.
- Writing is an explicit self-check, with no objective correctness/mastery. Review intervals are a lightweight experiment. Rewards acknowledge completing practice, including self-check, not only correct answers.
- Source audio was absent. No listening, speech recognition, microphone access, scheduled notifications, cloud push, QR transfer or Web Share UI is implemented. File exchange meets the initial sharing requirement.
- Device speech reads authored exercise text with an explicit language tag and prefers on-device voices where the platform offers them. It is verified only by unit tests against a fake synthesizer; no real iPhone, Safari or Firefox check has been made, and no offline-speech guarantee is given. Speech is not cancelled when leaving a round, and only exercise cards with authored `audioText` have a speak button.
- The fixture covers a real subset of Unit 1A; pronunciation and extended practice/vocabulary pages can be expanded. It is not a full digitization of the textbook.
- Future schema migrations must be explicit tested conversions. Unknown versions are rejected; no forward guessing. Import has a 5 MB cap. Course revisions must preserve stable concept semantics or bump the course version.
- The German study-copy adapter translates the bundled fixture's known English explanations without rewriting existing backups. Other imported explanations display as authored; the author must supply suitable instruction-language text.
- Focused rounds can contain only one exercise because the source-grounded library is finite. Repeating a prompt can increase practice progress, but this does not establish transfer or long-term retention. No automatic progression claim is made from that score.
- Import preview checks structure and exercise reachability, not factual correctness or teaching quality. Its availability counts describe a fresh learner; imported progress may unlock more. A preview is discarded on navigation or reload. After accepting replacement there is no automatic undo; export the current backup from the preview before switching if needed.
- Current schema 1.0 accepts `targetLanguage` values `en` and `fr`. Older app builds with the English-only schema reject French files; reopen the updated app before testing. Accents remain significant, canonical Unicode equivalents are accepted, and alternative apostrophes/punctuation must be explicitly authored in accepted answers.
